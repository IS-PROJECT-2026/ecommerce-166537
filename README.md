# Dubai-Kenya Fashion E-Commerce Platform

## Overview
This is a cross-border e-commerce web platform designed to facilitate the seamless ordering of fashion items from Dubai and shipping them directly to Kenya. The system serves as a functional storefront equipped with secure data management and real-time mobile payment processing.

## Live Deployment
The application is deployed live via GitHub Pages. 
**View the live site here:** https://is-project-2026.github.io/ecommerce-166537/
## Technologies Used
* **Frontend:** Next.js, Tailwind CSS, TypeScript
* **Database & Security:** Supabase (utilizing Row Level Security)
* **Payment Integration:** Pesapal API
